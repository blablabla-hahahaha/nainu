# nagi-vibe-coding 生成技能

本技能生成一套「让编码智能体自我治理」的架构，产物**完全适配当前项目**的技术栈与组织。

## 你要产出什么（交付清单）

按五层产出。**MVP 只需 #1、#3、#6 三件**。

| # | 产物 | 参考 | 说明 |
|---|---|---|---|
| 1 | 根 `AGENTS.md`（唯一指令入口） | [templates/AGENTS.md模板.md](templates/AGENTS.md模板.md) + [examples/01](examples/01-根AGENTS.md示例.md) | 常驻命令：每次会话都要看到的规则 |
| 2 | 各子树 `AGENTS.md`（按项目目录划分） | 同上 + [examples/02](examples/02-子树AGENTS.md示例.md) | 子树特有规则，层层收窄 |

## 生成流程

1. **给项目画像**：语言与类型系统 / monorepo 工具 / DI 或插件体系 / 测试框架与入口 / 构建发布流程 / 目录结构（哪些是「子树」）/ 命名约定 / 是否有 AI/agent 成分 / 是否双语。这决定「外部概念映射成什么」。
2. **读 `references/` + 套 `templates/`**：`references/` 是与任何特定项目无关的通用标准，只做「换项目名、命名、命令、入口」；`templates/` 是可直接填空的骨架。
3. **参考 `examples/` 做概念映射**：`examples/` 是一个完整实现长什么样的参考，用它做「外部概念 → 本项目等价物」的映射（见下）。
4. **过决策点映射表裁剪**：对每个「外部概念」问「本项目有对应物吗」——有就映射，没有就**删掉那条规则**，不为不存在的概念硬造规则。
5. **先接 3～5 条机械门禁**：从 `references/` 挑最在意的 3～5 条规则，各写一个校验脚本 + 一个「非法用例」证明它能失败。起步建议：一段一行、相对链接不死链、Agent Note 骨架、词数预算、TODO 分级。
6. **自检**（见下）。

## 决策点映射表（外部概念 → 本项目替换）

| 外部概念（参考实现里的） | 通用等价物 | 本项目替换提示 |
|---|---|---|
| 插件 / 生命周期受控注册（`ctx.effect`） | 生命周期受控的注册机制 | DI 容器 / 模块生命周期 / 钩子注册 |
| 接口定义 / 实现 / 调用方（seam） | 接口-实现-消费三角色 | 项目的抽象分层方式 |
| 扩展点 | 「新行为挂在哪里」的地图 | 插件/中间件/钩子体系 |
| 可回放状态日志（`SessionEventMap`） | 「可回放/可重建的状态日志」 | 日志/审计/事件溯源机制 |
| 「模型可见 ⟺ 已入日志」 | 「影响 AI 决策的输入必须可追溯」 | 无 AI 成分就删 |
| CLI 入口 / profile | 应用启动入口 | 项目入口命令 |
| 统一命名前缀（`@scope/pkg-*`） | 统一命名约定 | 项目命名约定 |
| monorepo 约束脚本 | monorepo 工具 + 约束 | 项目 monorepo 方案 |
| 每文件覆盖率门禁 | 覆盖率门禁 | 项目覆盖率阈值与范围 |
| 文档代码与源码同步（`type-equiv`） | 「文档里的代码与源码同步」 | 目标语言等价机制（或删） |
| 录制快照回放 | 确定性测试机制 | 金标/夹具回放机制 |
| 门禁聚合（`doc-sync`/`hygiene`） | 门禁聚合命令 | 项目脚本聚合 |
| 双语配对 + `.i18n.yaml` | 双语配对 | 项目语言对（或删，若单语） |
| 「模块对模型/用户可见的效应」 | 可见效应说明 | 无 AI 成分换成「用户可见效应」或删 |

## 边界规则

1. `references/` 内容可直接拷贝——只换「项目名、命名、命令、入口、语言」，不换「结构、原则、规则骨架」。
2. `examples/` 只参考结构——绝不把参考实现里的专属概念照搬进本项目。
3. 七原则不裁剪（除非明确不适用）：**一个事实一个家 / 指令分层 / 决策留痕 / 机械可检查 / 只写现状 / 双语同等权威 / 词数预算棘轮**。
4. 「机械可检查」是硬要求：一条规则若无法接上脚本，就降级为「评审约定」并明确标注，不要伪装成「门禁」。
5. 不硬造概念：项目没有的成分，删对应规则。

## 自检（交付前逐条核对）

- [ ] 根 `AGENTS.md` 每条规则「一句话 + 指向它的家」，没有复述细节。
- [ ] 子树 `AGENTS.md` 第一行声明「补充 `../AGENTS.md#conventions`」，不重复根规则。
- [ ] Agent Notes 有强制 `## Alternatives considered`，类别集合封闭且有脚本强制。
- [ ] 每条「值得保留的规则」都有校验脚本 + 一个非法用例。
- [ ] 指令入口只有 `AGENTS.md` 一种，无符号链接副本。
- [ ] 无参考实现专属概念残留（grep 外部概念名，出现即漏映射）。

生成后自问三句：**这条规则在本项目成立吗？这条能接上脚本吗？有没有外部概念残留？**
