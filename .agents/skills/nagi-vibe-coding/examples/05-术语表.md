# 术语表（terminology 实例）

---

## 通用规则
- 「中文」列是中文译文正文默认用词；若为英文，中文译文保留英文不翻译。
- 首次出现按「首次出现」列书写（带括号注释）；后续只写括号前部分。
- 「不要译作」列是严格禁止译法。
- 若某术语已作为另一术语组成部分被括注过，后续单独出现不再括注。

## 结构点评（生成时对照）
1. **三类表**（缩写类 / 英文类 / 双语类）区分「保留什么、翻译什么」。
2. **「首次出现」列**解决「正文第一次出现带注释、之后不带」的一致性问题。
3. **「不要译作」列**是禁止清单——把评审时反复出现的错误译法一次性写死。
4. **「备注」列**记录边界判断（如 `seam` 与 `extension point` 的区别、`SDK` 的精确所指）。
5. 关键心智：**翻译前就加载术语表**（「没注意到的词」最容易漂移），术语表是唯一权威、双向绑定。
