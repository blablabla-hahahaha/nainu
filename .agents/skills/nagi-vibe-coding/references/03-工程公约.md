# 工程公约清单

## 通用工程公约（照抄，换链接即可）
- **注册即副作用**：一切贡献都通过受生命周期管理的注册机制完成；注册函数返回 disposer（可释放句柄）。
- **运行时不变式断言「自有关系」**：检查权威事件流或可变数据，而不是服务/方法是否存在、插件元数据或副作用、或固定纯示例。
- **类型化事件用声明合并**与可合并扩展的 map；事件的元数据（模式、载荷）在声明处写清。
- **在判别标签上 switch**：封闭联合以 `assertNever` 收尾；可合并扩展的联合落到一个有文档的默认分支。
- **瀑布/中间件监听器必须调用 `next()`** 才能委派；不调用就返回会短路整条链。
- **新行为挂扩展点，不改核心循环**：改核心循环需同步改架构文档。
- **能力接缝由「接口定义 / 实现 / 调用方」三角色组成**：完整，绝不只一个角色；只有角色独立演化时才拆分。
- **优先用维护良好的依赖，而非手搓**——当它确实能删除自有代码和测试时。
- **模块边界处「显式 > 隐式」**：默认值是归属实现里的显式解析步骤，绝不是藏在调用点里的 `?? default`。
- **禁止硬编码可调参数**：随部署变化的都是已验证、可配置的字段；协议常量、外部规范、安全性不变量保持固定。
- **配置错误要大声失败**：能自足时在加载时失败，否则在最早可解析点失败；绝不静默跳过缺失引用。
- **跨边界的不透明 id 加品牌**（branded type），绝不裸 `string`。
- **在类型化的同进程边界信任类型系统**：不要只为静态接口已要求的值加运行时校验、兜底或恶意输入测试；在解析器/配置、队列、外部 JSON、持久化/文件、worker、进程、线上（wire）边界做校验。
- **源码平面 vs 产物平面，绝不混用**：静态门禁与测试解析到源码；消费构建后产物的门禁要显式声明该依赖。
- **保持编译器/构建 face 显式**：一个模块同时有多个编译目标时，用分面配置 + 仅 solution 的根。
- **空 `catch` 要写明吞掉了什么**、为什么别的都到不了这里；`try` 只包一条语句。
- **注释保持局部**：不复述代码、不解释远处行为（除非本地必需）、不扩写无关注释。
- **对称的平行值优先对称**：无解释的不对称通常意味着漏了一次抽取。
- **测试描述行为，不是正确性**：改过时行为连同其测试一起改，并在 PR 里说明为什么。
- **非平凡变更必须同 PR 附 Agent Note**；归档的 note 永久冻结。
- **客户端/用户可见文案本地化所有**：产品文案走类型化字典与翻译函数，硬编码被门禁拒绝。
- **每个工具的 UI 呈现要提前设计**：宿主呈现保持纯函数，渲染层从原始数据 + 持久化结果派生。
- **刻意选择 PR 历史**：拆分独立变更、在传播前修复引入该问题的 PR；重写用 `--force-with-lease`，远程有变动就中止，从不裸 `--force`。
- **标签/分类**：一个 PR 一个 `kind/*`，所有实质改动 `area/*`。
- **TODO 标记分级**：`FIXME`（发版阻塞）> `TODO`（尽快）> `XXX`（可能永远不）。
- **文件以恰好一个换行结尾**；`git diff --cached --check`（pre-commit）把关。

## 配套的「类型安全 + 文档纪律」（照抄）
- 一切在严格类型检查下编译；每个残留的「逃逸类型」（如 TS 的 `any`）都解释为何无法收窄。
- 每个模块与导出都有简洁 JSDoc 说明其非显而易见契约；函数式导出含参数/返回值文档（用脚本强制）。
- 评论与文档陈述**完整契约与上下文，而非推理过程**。用直接、具体的词，不用比喻。
- 把「值得机械检查的不变量」接入一个会被执行的顶层门禁，并证明每条被改动的接受路径都会拒绝一个非法用例。
- 文档随每次代码变更：受影响 README 与 JSDoc 契约一起更新。

## 可迁移要点
1. 这份清单是「**每条一句话 + 链接**」的典范——直接放进目标项目根 `AGENTS.md` 的 Conventions 段。
2. 每一条最终都能接上一条 `verify-*` 门禁（见 `08-机械门禁模式.md`）——写规则时就问「这条能不能接脚本」。
3. 目标项目没有 AI/agent 成分时，删掉「模型可见」类条目；没有 monorepo 时删掉「产物平面」类条目——**不为不存在的概念硬造规则**。
