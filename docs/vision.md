# Nainu AGI 愿景与演化路线（北极星文档）

## 1. 定位

本项目是验证 AGI 演化路线的实验性作品。它的命题是：智能可以被构造为可读、可测、可进化的工程资产——以 workflow 图为智能的原子单位，以 react 节点为受控自主点，以 schema 窄通道为保真机制，以神经元市场为信任与互联机制。

## 2. 问题陈述

### 2.1 主流两层路径的缺陷

主流 AGI 演化路径分两层：模型层提供基础智能，agent harness 提供工程入口。该路径存在三个结构性缺陷：

- **黑盒**：system prompt、user prompt、context 对使用者不可选；agent loop 的类型（react 或 plan-then-execute）与层数是黑盒。
- **无互联**：skill、MCP、CLI 等为单 agent 提供具身交互途径，但未提供 agent 之间的智能互联；单 agent 是孤立的神经元。
- **上下文失真**：agent 2 agent 范式中上下文在自由文本中传递，污染与失真不可控。

### 2.2 图编排路径的回应

workflow + LLM 的图编排路径具备可读性（流程直观可见）、可测试性（固定输入跑固定图）与可组合性（成熟 workflow 作为节点被调用）。其代价是自主性弱于 harness——本项目的设计以 react 节点受控地注入自主性。

## 3. 核心假设

本项目的基本假设：workflow 含 LLM 与 react 两种特殊节点；react 节点可插入前置与后置 sub-graph 处理上下文。由此推导出第一性原理：schema 窄通道。

## 4. 第一性原理：schema 窄通道

schema/契约窄通道是智能可组合且不失真的来源。它在三个尺度上一致：

- 节点内：LLM 输出经 post sub-graph 校验回 schema（失真闸门）。
- 节点间：edge 是 typed 的，只传递声明过的变量（见 [master-design.md](master-design.md) 的 DSL 变量引用语法）。
- workflow 间：调用只传输入 schema 的参数，不传上下文。

宽通道（允许部分上下文传递）是已识别的未来课题，当前挂起。

## 5. 系统语义

### 5.1 原子单位：workflow

workflow（图）是智能的原子单位：可读、可测、可复用。执行轨迹（trace）是一等公民——断点续跑、事件日志与上下文重放是 workflow 相对 harness 的结构性优势。

### 5.2 自主点：react 节点

react 是唯一自主机制：workflow 内部探索与 workflow 之间互联共用同一机制，平台只提供约束（深度、信任、schema）。react 节点可挂前置/后置 sub-graph 处理上下文。

### 5.3 信任机制：神经元市场

信任的载体从平台验证升级为社会信号，分三级演进：

- 人类绑定：使用者显式添加可调用的神经元白名单。
- 市场信号：平台提供市场，神经元可发布，使用者凭点赞、引用、描述决策。
- AI 自主搜索：市场指标成为 AI 自主检索的决策依据。

机械验证（schema 校验、测试集、judge 评分）与市场信号双轨并行；AI 搜索依据是验证级别、市场声誉、语义匹配度的组合。

### 5.4 治理旋钮

递归深度（级联层数）、绑定白名单（可调用集合）、运行时治理（审计、配额、沙箱）。

### 5.5 演化引擎：作者侧编排机器人

平台内置编排机器人，通过对话生成 workflow，解决 workflow 由人编辑的负担。AI 生成图的机械可验证性（DAG 合法性、schema 匹配）使其可进验证管线。

## 6. 演化路线

### 阶段一：基础闭环

workflow 图编排 + LLM/react 节点 + pre/post sub-graph + typed edges + 绑定白名单 + 递归深度控制。

### 阶段二：验证侧

测试集、judge 评分、验证管线；验证通过的 workflow 成为候选神经元。

### 阶段三：神经元市场

发布、引用、点赞、描述；声誉积累；市场信号反哺信任决策。

### 阶段四：运行时治理 + AI 搜索

审计、配额、沙箱成熟后开放 AI 自主检索；机械验证与市场信号双轨运行。

## 7. 挂起课题

- 宽通道互联：神经元对神经元的直接上下文交互。
- trace → subgraph 编译：验证过的路径内嵌为节点（自进化后期形态）。

## 8. 与现有实现的关系

代码已落地本愿景的地基：Master 的 DAG 调度执行（[master-design.md](master-design.md)）与 Redis 上下文存储已实现，节点输入为字段级引用（INTERNAL_REF / CUSTOM / EXTERNAL_REF）；LLM / react 节点、Worker 插件执行、断点续跑与 workflow 间调用是尚未实现的蓝图。愿景约束这些模块的演进方向，实现细节由各归属文档承载。
